# 0006: Oxlint, Oxfmt, and a pre-commit gate

- **Status:** accepted
- **Date:** 2026-10-18

## Context

The workspace had no automated quality gate. Formatting and lint conventions
were left to individual editors, and nothing prevented broken types or a broken
production build from reaching `main`.

## Decision

Use the Oxc toolchain for static analysis and formatting, and Husky for a
pre-commit hook:

- **Oxlint** (`.oxlintrc.json`) with TypeScript, unicorn, oxc, import, promise,
  and React plugins. `correctness` is an error; `suspicious` and `perf` are
  warnings. The `lint` script passes `--deny-warnings`, so warnings also fail
  the gate.
- **Oxfmt** (`.oxfmtrc.json`) with an 80-column, double-quote, trailing-comma
  style. Generated code (`routeTree.gen.ts`) and the lockfile are ignored.
- **Husky** runs `lint`, `typecheck`, and `build` on every commit, in that
  order, with `set -e` so the first failure aborts the commit.

## Consequences

- One toolchain instead of ESLint + Prettier, and both binaries are fast enough
  to run on the whole repo.
- `--deny-warnings` means a warning blocks a commit. This keeps the tree clean,
  but adding a rule at warning level can break unrelated commits; lower it to
  `--warn` or fix the code when that happens.
- The hook runs the full build, not just the changed package. That is slower per
  commit but guarantees the committed tree builds.
- `routeTree.gen.ts` is regenerated by the build and excluded from lint/format,
  so generated output never causes churn.
- Husky requires `pnpm install` (which runs `prepare`) before hooks are active;
  a fresh clone has no hook until then.

## Alternatives considered

- **ESLint + Prettier** — the default choice, but slower and requires a larger
  dependency graph for the same coverage.
- **lint-staged** — would limit work to changed files. Deferred because the
  typecheck and build gate is repository-wide by nature.
- **CI-only checks** — catches problems later and costs a round trip; the hook
  gives faster feedback at low cost for a repo this size.
